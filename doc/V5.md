# 第五阶段代码实现完成

所有四类分块策略已实现完毕。以下是完整的文件清单：

### 新增/修改的文件

**分块策略模块：**
- `src/herta/kb/chunker.py` - 扩展 BaseChunker，支持所有策略的统一接口和 ChunkConfig
- `src/herta/kb/simple_chunker.py` - 固定大小滑动窗口分块
- `src/herta/kb/semantic_chunker.py` - 基于语义相似度的分块（相邻句子 embedding 相似度低于阈值时切分）
- `src/herta/kb/selector.py` - AutoSizeChunker，自动选择最优分块参数（基于启发式评分）
- `src/herta/kb/proposition_chunker.py` - 基于原子事实命题的分块（使用 LLM 提取命题）

**模块导出：**
- `src/herta/kb/__init__.py` - 更新导出所有分块器

**知识库构建器：**
- `src/herta/kb/builder.py` - 更新支持 ChunkConfig 参数传递

**CLI：**
- `src/herta/cli/buildkb.py` - 支持所有分块策略参数，生成 build_report.json

### 支持的 CLI 参数

```bash
# 基础参数
herta buildkb --source gdwx --chunk-strategy simple --chunk-size 500 --chunk-overlap 50

# Semantic 策略
herta buildkb --source gdwx --chunk-strategy semantic \
    --semantic-threshold-percentile 0.5 \
    --semantic-min-sentences 2 \
    --semantic-max-chars 2000

# Auto-size 策略
herta buildkb --source gdwx --chunk-strategy autosize \
    --candidate-sizes "300,500,800,1000" \
    --candidate-overlaps "50,100" \
    --selection-output ./selection_report.json

# Proposition 策略
herta buildkb --source gdwx --chunk-strategy proposition \
    --proposition-model glm-5.1 \
    --max-propositions-per-chunk 10 \
    --proposition-batch-size 5 \
    --proposition-cache
```

### 输出文件

构建完成后会生成：
- `chunks.jsonl` - 分块数据
- `meta.json` - 构建元数据
- `embeddings.npy` - 向量数组
- `vector.index` - FAISS 索引
- `build_report.json` - 构建报告（新增，记录策略、参数、统计等）

### 验证命令

```bash
# Simple 策略（默认）
herta buildkb --source gdwx

# Semantic 策略
herta buildkb --source gdwx --chunk-strategy semantic

# Auto-size 策略
herta buildkb --source gdwx --chunk-strategy autosize

# Proposition 策略
herta buildkb --source gdwx --chunk-strategy proposition
```

所有策略都可运行，build_report.json 会记录最终使用的策略和参数。
