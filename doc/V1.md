# 七、验证步骤与运行方式

### 7.1 环境创建与安装命令

```bash
# 1. 创建虚拟环境
conda create -n herta-rag python=3.12 -y

# 2. 激活环境
conda activate herta-rag

# 3. 升级 pip
python -m pip install --upgrade pip

# 4. 安装项目依赖
pip install typer pydantic numpy faiss-cpu python-docx PyMuPDF zai-sdk

# 5. 以 editable 模式安装项目
cd /home/aether/paimon/herta
pip install -e .
```

或者使用 conda 环境文件：

```bash
# 创建并激活环境
conda env create -f environment.yml
conda activate herta-rag

# 安装项目
pip install -e .
```
